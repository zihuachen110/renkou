**口径**：常住人口·年末数。全国趋势用年鉴/国家数据逐年序列；省级地图着色为 **2000–2024**（年鉴分省 + 六普/七普精确值）。台港澳无本站省级着色。全国与分省来源不同时，占比仅作示意。**2025** 分省年末数尚未见全国年鉴刊出（全国 2025 为 1% 抽样推算）。

**边界说明**：任何国界/争议地区表述以国家正式公布为准；本站底图不构成领土主张或官方立场。

**下架**：若来源方要求删除，替换/移除对应 JSON 与 GeoJSON 后重新部署即可。
