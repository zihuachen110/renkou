## 1. 一句话定义

面向公众的**非官方人口数据探索站**：以官方公开统计为来源，用「默认有意义的视图」引导用户回答三个问题——**和全国比怎样、各地怎么分布、近年怎么变**；支持国→省→市下钻、图表/表切换、溯源下载；广告为独立可开关模块。

**MVP 主轴**：常住**总人口**（全国多年度趋势 + 省/市空间分布）。  
**MVP 专题**：老龄化率 2010→2020（入口级，不抢首页主叙事）。

---

## 2. 产品原则

1. **引导式探索**：进入即展示有意义的默认视图，不出现「先选一堆维度再出图」。
2. **三问题优先**：首屏与导航直接回应对比 / 分布 / 趋势，不做数据目录首页。
3. **图表白名单**：全站复用有限图表类型，用户学一次即可。
4. **可信优先于炫技**：口径、来源、更新日期是界面的一部分，不是脚注。
5. **渐进披露**：首屏筛选只保留地区层级 + 年份；性别/城乡等进第二步。
6. **静态优先**：无后端库；更新 = 换 JSON + 重新部署。

---

## 3. 用户要回答的三个问题

| # | 问题 | MVP 如何回应 |
|---|---|---|
| Q1 | 这里和我熟悉的地方比，怎么样？ | 详情卡：**相对全国占比**（省/市人口 ÷ 全国）；全国态提示「当前为全国口径」 |
| Q2 | 这个指标内部怎么分布？ | **分级统计地图**国→省→市 + **条形排名** Tab |
| Q3 | 它是在变好还是变坏？ | Hero **各年折线**；点年份同步地图/排名/表 |

---

## 4. 图表白名单（全站锁定）

| 类型 | 用途 | MVP |
|---|---|---|
| 折线图 | 时间趋势（Q3） | ✅ 全国各年总人口 |
| 分级统计地图 | 空间分布（Q2） | ✅ 总人口着色 + 下钻 |
| 条形排序图 | 横向对比 / 排名（Q1/Q2） | ✅ 探索器「排名」Tab |
| 表格 | 兜底视图 + 下载 | ✅ 与图同数据一键切换 |
| 人口金字塔 | 年龄×性别标准语言 | ❌ 第二步专题 |
| 双地区并排 / 双年叠合 | 深度对比 | ❌ 第二步 |

同一指标页必须支持：**地图 ↔ 排名 ↔ 表格** 切换（同一探索器）。

## 5. 目标用户与场景

| 用户 | 场景 | MVP |
|---|---|---|
| 普通公众 | 查全国/家乡人口与变化 | 默认全国视图 + 下钻 + 相对全国 |
| 学生/研究者 | 作业、初步分析 | 表、CSV/JSON、来源链接 |
| 媒体/自媒体 | 可引用结论与截图 | 干净首屏、排名、专题入口 |
| 广告主（后期） | 展示广告 | 占位；后期 AdSense |

**不做（MVP）**：注册、评论、UGC、县级、个体数据、实时、预测、3D/大屏、性别等多维筛选、金字塔。

## 7. 默认视图与筛选（渐进披露）

**进入 `/` 的默认状态：**

- 指标：常住总人口  
- 地区：全国  
- 年份：数据内最新年  
- 探索器 Tab：地图  
- 右侧：全国总值 + 省级 Top 排名  

**首屏可调维度（仅 2 个）：**

1. 年份（点趋势图）  
2. 地区（地图下钻 / 点排名）  

**第二步再加**：「更多筛选」（性别、城乡等）、双地区对比、URL 同步分享状态。

## 8. 主界面模块（P0）

| 模块 | 需求 | 验收 |
|---|---|---|
| Hero 总值 | 全国总人口大数字 + 口径 + 来源链 | 5 秒内建立「看人口」认知 |
| Hero 趋势 | 各年折线，可点年份 | 切换后探索器同步 |
| 探索器 | 地图 / 排名 / 表同一模块 | Tab 切换数据一致 |
| 地图 | 国→省→市分级着色 | 可返回上一级；图例清晰 |
| 详情卡 | 选中地区人口（亿人）+ **相对全国** + 来源 | 全国/省/市文案正确 |
| 排名 | 按数值降序条形；可点选中 | 与地图联动 |
| 表格 | 可排序；与当前年一致 | 可下载 |
| **元数据条** | 固定展示：来源、口径、更新/获取日期 | 探索器下方或侧栏常驻 |
| 专题入口 | 老龄化引导，不抢 Hero | 文案级入口即可 |
| 广告位 | 1–2 个占位，可关 | 标「广告」；默认不加载脚本 |
| 非官方声明 | 顶栏细条 | 每页可见 |

**Tooltip（实现时）**：悬停显示数值、单位、年份、来源摘要、口径关键词（常住人口）。

## 9. 数据需求

### 9.1 源优先级

1. 国家统计局公开数据 / 年鉴（全国、省级年度人口）  
2. 六普 / 七普公报与汇总（市级总人口、老龄化专题）  
3. 各省公报交叉校验  
4. 边界：仅可公开展示的授权清晰数据  

### 9.2 MVP 时空范围

| 项 | MVP |
|---|---|
| 层级 | 国家 / 省 / 地级市 |
| 主指标时间 | 全国（及尽量省级）**多年度序列**；市级以可得年份为准（可仅普查年） |
| 主指标 | `population_total` 常住总人口 |
| 专题 | `aging_rate` 2010 与 2020（市或省，按数据可得性） |

市级多年份不全时：**非普查年地图停在省级并文案提示**——允许。

### 9.3 字段（最小集）

同前版：`regions`、`observations`、`sources` / `meta.json`；下载文件必带来源字段。

### 9.4 口径

- 总人口：写死 **常住人口**（页面与下载注明）。  
- 老龄化专题：上线前锁定 65+ 或 60+ 之一，不可混用。  

### 9.5 工程

- `etl/` 开源；产物静态 JSON/CSV + `meta.json`  
- 区划变更映射表；`unmatched.md`  
- 市界按省分片加载

## 10. 广告（可开关）

```text
ads.enabled = false
ads.provider = "none" | "adsense"
ads.slots = ["below_explore"]
```

不弹窗、不遮挡探索器；后期优先 Google AdSense（境外站）；国内联盟基本不可行。

## 11. 非功能

| 类别 | 要求 |
|---|---|
| 部署 | Cloudflare Pages；HTTPS；可用 `*.pages.dev` |
| 架构 | SSG；无后端库 |
| 性能 | 首屏 &lt; 3s；已加载数据下交互 &lt; 200ms |
| 无障碍 | 对比度 ≥ 4.5:1；不单靠颜色；键盘可用；字号可放大不破版（目标） |
| 数字 | 展示优先「亿人」；表/下载可用「万人」；tabular figures |
| 下架 | 24–48h 可下线对应数据 |

技术栈：Astro + TS + MapLibre + ECharts(排名) + Tailwind + Python ETL + CF Pages。

---

## 12. 合规（主需求）

非官方声明；来源/获取日/口径；隐私与广告说明；授权记录在 `docs/data-provenance/`；不做个体与非公开爬取；广告收入自行税务申报。

---

## 13. 分两步落地

### 第一步（1–2 周 · MVP）

- 图表白名单中的线 / 地图 / 条 / 表  
- 指标页模板：默认视图 + 年份/地区 + 图表切换 + 元数据 + 相对全国  
- 填入：总人口；老龄化仅入口/轻专题  
- 上线静态站  

### 第二步（迭代）

- 金字塔专题、城镇化等灌入同一模板  
- 双地区对比、URL 分享状态、批量下载  
- AdSense、更多筛选  
- **不做优先**：3D 地图、大屏风
